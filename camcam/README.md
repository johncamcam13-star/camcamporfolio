# John Carlo Camcam | Student IT Portfolio (BSIT)
## Bachelor of Science in Information Technology • Gold & Silver Edition

A full-stack, responsive student portfolio web application engineered for **John Carlo Camcam** using **PHP 8** and **MySQL**, styled with a **Modern Luxury Gold and Silver** design system. Tailored specifically for IT student showcase and **OJT / IT Internship (500 Hours)** recruitment.

---

## 🌟 Student IT Portfolio Highlights

1. **Student Developer Credential ID Card (Hero Section)**:
   - High-tech smart card layout with simulated microchip, student ID code (`BSIT-2026-JCC`), and candidate badge.
   - Prominently showcases John Carlo Camcam's formal suit-and-tie photo in a dual-metallic gold & silver gradient border.
   - Status indicators: `🟢 Available for OJT / Internship (500 Hours)` and competency chips (Full-Stack PHP, MySQL RDBMS, Arduino IoT, Systems Analysis).
   - Quick action triggers for viewing the Student CV and copying the candidate's email address.

2. **Academic Journey & Curriculum Foundation**:
   - Outlines key academic milestones across the BSIT curriculum:
     - **Web Systems & E-Commerce (IT 301)**: PHP 8, MySQL CRUD, session-based cart computation.
     - **Database Management & Modeling (IT 204)**: 3NF schema normalization, ERDs, PDO prepared statements.
     - **Embedded Microcontrollers & IoT (IT 402)**: Arduino C++, ultrasonic sensors, relay valve control.
     - **Systems Analysis & Software Engineering (IT 303)**: SDLC, DFDs, documentation, and Git.

3. **The Three Flagship Projects**:
   - Complete 3-column responsive grid with 16:9 custom vector mockups, category filters, and interactive modals:
     1. **Tapseafood: Online Food Ordering System** (Web Systems Project / E-Commerce)
     2. **Hotel Online Booking System** (Database Management & Reservation System)
     3. **Smart Arduino Water Dispenser** (Embedded Systems & IoT Hardware Project)

4. **Multi-Tab SQL Code Studio**:
   - Interactive code viewer with tabs:
     - `📄 database.sql`: DDL schema for `projects`, `skills`, `contact_messages`, and `profile_info`.
     - `⚡ project_queries.sql`: Real-world queries executed via parameterized PHP-PDO statements.
     - `🔗 relational_schema.sql`: Referential integrity, CASCADE rules, and foreign keys.
   - Features 1-click clipboard copy with animated status feedback and direct `.sql` file download.

5. **Technical Skills Matrix**:
   - 8 core competencies categorized by domain (Backend, Database, Hardware/IoT, Methodology) with animated gold and silver progress meters.

6. **Student Resume (CV) Showcase & Modal**:
   - Dedicated on-page curriculum vitae section (`#resume`) and high-resolution modal showcasing John Carlo Camcam's official student resume (`student_resume.png` / `student_resume.pgn`).
   - Includes career objectives, educational timeline (Datamex College of St. Adeline BSIT & Western Bicutan NHS), core skills, character references, and 1-click Download and Print / Save as PDF actions.

7. **OJT Recruitment & Direct Inquiry Form**:
   - Clear candidate details for recruiters and coordinators (500-hour practicum, preferred tracks, contact info).
   - Working contact form submitting directly to MySQL via PDO prepared statements with success/error alerts.

## 🚀 How to Run in XAMPP

1. Open your **XAMPP Control Panel**.
2. Click **Start** for **Apache** and **MySQL**.
3. Open your browser and navigate to:
   ```
   http://localhost/camcam/
   ```
4. The database `portfolio_db` and tables will automatically initialize on your first visit!
